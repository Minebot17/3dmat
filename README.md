# Cellular 3D

Трёхмерный клеточный автомат в браузере. Симуляция и рендер целиком на GPU (WebGL2), без зависимостей и сборки.

## Запуск

```bash
npm start
```

Откройте http://localhost:5173. Подойдёт любой статический сервер: ES-модули не работают при открытии через `file://`.

## Возможности

- **Правила** в нотации `выживание/рождение/состояния/окрестность`, например `4/4/5/M` или `5-8/6,7,9,12/4/M`. Окрестности: `M` (Мур, 26 соседей), `E` (грани и рёбра, 18), `VN` (фон Нейман, 6). Если состояний больше двух, это правила типа Generations: клетка, которая не выжила, угасает через промежуточные состояния.
- **Случайные правила и мутации.** Каждого кандидата воркер прогоняет на CPU-симуляции 36³ с той же затравкой, что будет на GPU. Правила, которые вымирают, заливают объём, превращаются в сплошной ком или не растут, отбрасываются. Предыдущее правило возвращается клавишей `Z`.
- **Каталог**: сохранение с превью (localStorage), поиск, переименование, удаление, экспорт и импорт JSON, ссылка с полным состоянием в `#c=…`. Во вкладке «Встроенные» 19 классических правил с настоящими превью, они рендерятся в фоне.
- **Анимации переходов**: новые клетки «выпрыгивают» (ease-out-back), умирающие плавно сжимаются, цвет перетекает между состояниями.
- **Настройки**: сетка от 32³ до 256³, скорость, тор, форма, плотность и симметрия затравки, 11 палитр, 5 режимов раскраски, 4 сцены, тени, AO, контуры, свечение, ореол, туман, свет, срез по осям, демо-режим.

## Как устроено и почему это быстро

| Этап | Реализация |
|---|---|
| Состояние | Две 3D-текстуры `RGBA8UI` (ping-pong): состояние, предыдущее состояние, возраст |
| Шаг | Фрагментный шейдер пишет 4 z-слоя за проход через MRT. Суммы соседей по плоскостям общие для соседних слоёв, поэтому на клетку уходит ~13 выборок вместо 27 |
| Затравка | Генерируется на GPU из хеша, без загрузки данных. В воркере та же функция, совпадение побитовое |
| Пропуск пустоты | Сводка блоков 4³ (`RGBA8`) для двухуровневого DDA. Её же трилинейная выборка даёт мягкое AO, а редукция даёт статистику |
| Рендер | Raymarching вокселей (блоки → клетки), воксельное AO, жёсткие тени, пол, туман |
| Пост-эффекты | HDR → dual-filter bloom → FXAA + ACES + виньетка |
| Адаптивность | Разрешение подстраивается под реальное время GPU (`EXT_disjoint_timer_query_webgl2`), а не под FPS, поэтому троттлинг фоновой вкладки его не сбивает. Кадр не перерисовывается, если ничего не изменилось |
| Статистика | Редукция на GPU, чтение после fence в начале кадра, до новой работы |

Замер на RTX 3080 Ti: шаг 96³ занимает ~0.7 мс, шаг 256³ (16.7 млн клеток) ~9 мс, кадр 1920×1080 с тенями ~6 мс.

## Управление

| Клавиша | Действие |
|---|---|
| `Пробел` | пауза / пуск |
| `→` или `.` | один шаг |
| `R` / `Shift+R` | перезапуск / с новым зерном |
| `N` / `M` | случайное правило / мутация |
| `Z` | предыдущее правило |
| `S` / `C` | сохранить / каталог |
| `P` / `H` / `F` | панель / скрыть интерфейс / полный экран |

Мышь: перетаскивание вращает, колесо приближает, двойной клик сбрасывает камеру. На тач-экранах работает щипок.

## Структура

```
index.html            разметка интерфейса
css/style.css         стили
js/main.js            состояние приложения, цикл кадров, UI-сценарии
js/automaton.js       GPU-симуляция, затравка, сводка блоков, статистика
js/renderer.js        raymarch, bloom, композитинг
js/shaders.js         все GLSL-шейдеры
js/rules.js           нотация, пресеты, генерация и мутация правил
js/evaluator.worker.js отбор интересных случайных правил на CPU
js/thumbs.js          фоновые превью встроенных пресетов
js/catalog.js         каталог в localStorage, импорт и экспорт
js/camera.js          орбитальная камера
js/ui.js, icons.js    панель настроек, карточки, тосты, иконки
js/palettes.js        палитры и сцены
server.js             статический сервер для разработки
```

В консоли браузера доступен `cellular` (`cellular.app.state`, `cellular.sim`, …), с ним удобно экспериментировать.
